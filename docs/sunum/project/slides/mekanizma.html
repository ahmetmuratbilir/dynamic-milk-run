Neden? Tampon farklı süreyi örtüyor

Periyodik (P2)

Tampon çevrim + teslim süresini örter → aynı kartla daha çok stok.

e-Kanban (P3)

Tampon yalnızca teslim süresini örter → daha az stokla aynı hizmet.

Bu yüzden eşit kartta dijital önde, politika-tutarlı formülde geleneksel kartı fazla tutup öne geçebiliyor.
